# Criando um Infoproduto

## Minerando Infoprodutos Validados

**Aula:** 314

- Primeira etapa: encontrar ofertas já vendendo para minerar como base
- Usar Minerar.com (ou Biblioteca de Anúncios do Facebook) para espionar concorrentes
- Filtros essenciais: mínimo 2 anúncios ativos rodando máximo 40 dias (ofertas novas com potencial)
- Palavras-chave para busca: "apenas", "kit", "pack", "receita secreta", "ritual", baseadas no nicho
- Acompanhar crescimento: monitorar quantidade de anúncios crescendo (3 para 15 anúncios = sinal positivo)
- Evitar ofertas com rosto famoso (direitos autorais) ou WhatsApp (não é automático)
- Ofertas ideais: low ticket, tráfego direto, sem pessoa real por trás
- Exemplos analisados: 52 lições escola dominical (R$10-27), estruturador sermões, kits
- Ticket médio importante: ordem de compra com bônus pode elevar ticket de R$10 para R$54
- Aplicar técnica: salvar oferta na ferramenta e acompanhar crescimento por dias para validar

## Modelando seu Site

**Aula:** 315

- Usar Lovable (IA para criar sites) ou similar para modelar página de vendas
- Copiar página de referência, colar em prompt: "melhore deixando clean, espaços para mocups"
- Gerar mockups com GPT pegando referência visual (PNG, sem fundo, sem poluição)
- Adicionar mocup principal logo abaixo do subtítulo
- Estrutura básica mockups: principal em destaque, imagens dos bônus (4-5)
- Hostigg para domínio + hospedagem: plano premium, domínio genérico (fórmulacursos.online)
- Configurar subdomínio ou domínio principal, conectar em Lovable via settings
- Alternativa: usar domínio lovable.build para teste (não recomendado final)
- Preferência: domínio .com ou .com.br passa mais credibilidade
- Setup rápido: Lovable + Hostigg = página no ar em horas

## Criando seu Infoproduto

**Aula:** 316

- Entregáveis: produto principal + 4 bônus + order bumps (upsells no checkout)
- Usar ChatGPT para gerar 10 imagens de uma vez (requer Plus)
- Estrutura: capa + 9 páginas temáticas (versículos, atividades, etc)
- Converter para PDF agrupando múltiplas gerações de 10 imagens
- Alternativas: Gama App, Cloud Code ou ChatGPT puro
- Ordem bumps gerados igual: kit colorir, kit teatrinho, kit louvorozinho, kit datas comemorativas
- Qualidade importa: não vender e-book lixo, conteúdo deve entregar valor real
- Dica: quanto mais valor agregado, mais irresistível a oferta
- Processamento: gerar 10 imagens, pedir "transforme em PDF", download e reutilizar

## Cadastrando seu Infoproduto

**Aula:** 317

- Plataforma: Wiven (ou Hotmart, Kirvano) para venda e pagamento
- Tipo produto: ebook, curso, SaaS, digital (Wiven é mais acolhedor)
- Campos básicos: nome, categoria, prazo reembolso 7 dias
- Imagem do produto gerada em GPT (solicitar tamanho específico)
- Descrição + link página de vendas + e-mail + WhatsApp suporte
- Entrega: Área de Membros (recomendado) ou Arquivo (mais simples)
- Estrutura área de membros: módulo principal + módulo bônus
- Cada módulo: capa + aulas com descrição, sem vídeo (ocultar vídeo)
- Upload arquivos: PDF principal, PDFs bônus em módulo separado
- Capas módulos: gerar em GPT com tamanho Wiven (pedir tamanho específico)
- Checkout personalização: desativar boleto, deixar Pix+cartão, adicionar banner acima
- Pixels: integrar Facebook Pixel para rastreamento (ID + token)
- Order bumps: criar produtos separados, vincular ao principal no checkout
- Validação: testar checkout, usar Meta Pixel Helper para confirmar rastreamento
- Dois planos: básico (R$10) + completo com bônus (R$27,90)

## Modelando Criativos

**Aula:** 318

- Não copiar anúncios da oferta original (já estão saturados no Facebook)
- Buscar no TikTok vídeos representativos (sem rostos reais ou experts)
- Estrutura criativo: promessa + capa produto + preço + CTA
- Alternativa: divulgar a benefício em destaque no meio
- Gerar criativos com Win Ads ou IA (ferramentas de vídeo IA com modelos)
- Process video: pegar cena TikTok + editar em CapCut + sobreposição produto
- Copy do anúncio: usar estrutura de headlines (pedir ao GPT variações)
- Testar: 100% TikTok, 100% IA ou híbrido (50/50 com split-screen)
- Formato testado: criativo com modelo (Win Ads) performou bem (200 curtidas)
- Variar: mesmo nicho pode sair em francês, espanhol, etc (mesma metodologia, idioma diferente)
- Mínimo 3-5 criativos para testar em primeira campanha
