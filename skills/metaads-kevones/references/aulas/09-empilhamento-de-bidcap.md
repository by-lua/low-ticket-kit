# Empilhamento de BidCap

## Empilhamento de BidCap

**Aula:** 281

Explicação prática de BidCap (limite de lance) e estratégia de empilhamento para aumentar ROI mantendo CPA sob controle. Demonstração com gerenciador de anúncios ao vivo com resultados reais.

### O Que é BidCap

- Limite de lance: quanto você está disposto gastar no leilão para mostrar criativo para possíveis leads
- Facebook, por padrão, usa "Valor ou Volume Mais Alto" (maximiza conversão mas gasta prioritariamente toda verba)
- BidCap coloca você no controle dos gastos por impressão/clique

### Configuração e Aplicação

- Criar campanha → Continuar → Nível de campanha vem pré-configurado em "Valor/Volume Mais Alto"
- Mude para "Limite de Lance" (outras opções)
- A nível de conjunto aparece campo para inserir CPA máximo desejado
- Não gastar pouco (R$60, R$100 por dia): infle orçamento inicial (R$10.000+) pois Facebook tem travas internas
- BidCap reduz gasto real dentro daquele teto que você definiu

### Empilhamento de BidCap (Inovação da Estratégia)

- Não é apenas uma campanha BidCap isolada (prática comum)
- Múltiplas campanhas BidCap empilhadas + isolamento inteligente + escala diária/progressiva
- Estrutura 1:1 (1 campanha, 1 público, 1 anúncio) em cada BidCap
- Cada campanha tem limite de lance entre R$35-R$45 (exemplo: CPA médio conhecido R$40)
- Algumas campanhas não gastam: aumente verba para R$50.000 até começar distribuição

### Validação e Combinação

- Testar BidCap só após oferta já validada e CPA conhecido
- Não recomendado para teste de infoproduto novo (desperdício de tempo/verba em configuração)
- Melhor: duplicar campanha validada em "Conversão Normal", mudar só a estratégia para BidCap
- Mesmo criativo em duas campanhas (uma conversão normal, uma BidCap) gera comparação de performance

### Resultados Práticos Mostrados

- Uma campanha BidCap isolada: R$596 investido → R$872 retorno (ROAS 3.14) = R$275 lucro
- Hoje (filtro 24h): R$374 investido → R$1.000+ retorno (ROAS 2.8) = R$700+ lucro
- Mesma oferta validada: R$19.000 em conversão → R$31.000 retorno (ROAS 1.6) = R$11.000 lucro em 2 meses
- Empilhamento: 57 vendas/7 dias com R$1.435 investido → R$3.290 retorno (ROAS 2.28) = R$1.858 lucro

### Integração com Outras Estratégias

- Não funciona BidCap sozinho
- Combine com isolamento inteligente, escala diária, escala progressiva (todas da Seleta Comunidade)
- BidCap + conversão normal = melhor resultado que isolado
- Unindo BidCap + Conversão (últimos 7 dias): R$669 investido → R$6.839 retorno (ROAS 10.2x) = R$6.170 lucro

### Hack para Escala

- Para testar infoproduto: não use BidCap (muito tempo em setup)
- Para escalar oferta já validada: pegue campanhas com criativos validados, duplique, mude só a estratégia para BidCap
- Resultado: teste criativo com dois tipos de estratégia simultaneamente com mesma verba

### Avisos Críticos

- Não use BidCap em conta de anúncios isolada (risco alto)
- Só funciona bem quando você já validou oferta, conhece CPA, tem criativos prontos
- BidCap em oferta não validada = queimar tempo/dinheiro em configuração
- Replicar em paralelo: campanhas conversão continuam normais, duplicadas em BidCap para teste
