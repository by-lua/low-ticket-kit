## SaaS Financeiro - Copie, Cole e Lucre!

**Aula:** 96

- Produto Mordomis: SaaS financeiro gerenciamento fluxo caixa (não ebook, plataforma real)
- Estrutura Mordomis: receitas, despesas, transações, dívidas, categorias, relatórios, metas, módulo mercado/veículos
- Validação: R$3000 investido anúncio → R$9000 retorno mês passado (ROAS 3x)
- Atualmente: R$838 investido últimos 6 dias → R$900 retorno (ROAS ~1.1)
- Total período: R$5439 investido → R$16k+ faturado (~3x retorno)
- Afiliação: 60% comissão (venda recorrente, pessoa renova = você recebe 60% renovação também)
- Diferenciais: suporte equipe, recuperação vendas carrinhos abandonados, atualizações constantes
- Funil: construído Lead (plataforma automação marketing com 8 etapas até compra)
- Planos: R$57 mensal, R$197 semestral, R$297 anual (escolhe qual rodar)
- Acesso funil: criar conta Inlead (link drive) → solicitar funil → equipe compartilha 24h → alterar links afiliado
- Criação conta: usar link Google Drive fornecido → clicar "solicite seu funil" → preencher e-mail conta Inlead
- Regras: NÃO criar Instagram (só página Facebook), proibido spam direto, permitido criar anúncios com seu rosto testando
- Criativos: anúncio experiência (você testando plataforma) vende mais que promoção direta
- Funil readiness: funil já pronto, só colocar links afiliado, NÃO alterar estrutura
- Estrutura campanha: templates, interesses, direcionamentos, públicos já definidos
- Comissão por venda: até R$168 por venda completada

## Estruturador de Sermões - Copie, Cole e Lucre!

**Aula:** 97

- Produto: ferramenta estruturador sermões (não ebook/curso, app funcionando)
- Validação: "tá vendendo muito" com múltiplas vendas reais
- Tipo negócio: soft product (tool) recorrente não descartável tipo ebook
- Funil Lead: dinâmico com quiz interativo (pergunta se pastor/pregador/servo)
- Etapas funil: personagem saudação → dor (pregação problema) → depoimento → desenvolvimento dor → desenvolvimento oferta → feedback → vídeo explicação → prova social → ancoragem escassez → oferta revelada → checkout
- Vídeo vendas: programador (John sócio) mostra funcionamento prático ferramenta
- Delay botão: aparece segundos após pessoa assistir vídeo (tática conversão)
- Orderups: 2 produtos adicionais no checkout (elevam ticket R$47→R$66)
- Duas ofertas: R$47 (promo) ou R$57 (padrão) escolher qual rodar
- Afiliação: 80% comissão (ferramenta = custos constantes por isso não 100%)
- Acesso: criar conta Kirvano 100% configurada (nome, e-mail, telefone, documento, conta bancária)
- Solicitação: preencher formulário funil Lead 24h retorno
- Funil Lead: alterar apenas pixel + link afiliado (via etapa 11 botão compra)
- Estrutura campanha: orçamento R$45 CBO, 2 públicos (aberto + segmentado com interesses), 3-5 criativos
- Público segmentado: homens 22-55 Brasil + interesses específicos (listados estrutura)
- Criativos: 7 validados fornecidos (criativo 02 melhor convertedor = base para variações)
- Conselho: não rodar criativos originais igual concorrentes, sempre criar variações
- Detalhes: coloca sempre pixel Kirvano + estruturação funil antes subir campanha

- Fonte: transcricoes/curso-id15/20-ofertas-validadas/02-Estruturador_de_Sermoes_-_Copie_cole_e_lucre.md

## Oferta em Dólar - Gênio da Música

**Aula:** 171

- Produto: gerador música com IA (permite usuário criar, lucra por ouvintes)
- Preço: $9 (pouco) → você recebe 80%+ dólares (mais que 5x real)
- Porque não 100%: produto próprio, atualizações constantes, recuperação vendas
- Funil: quiz interativo não página estática (aumenta conversão, diminui custo)
- Plataforma funil: Inlead (não domínio pessoal, sem hospedagem, sem código)
- Link afiliação: Hotmart fornece (copiar link venda → colar botão compra funil Inlead)
- Config funil Inlead: pixel Facebook (ID + HTML script) em configurações
- Público campanha: mundo todo excluir (Brasil, Guiana Francesa, Venezuela, África)
- Idioma: espanhol (vender Latam em dólar)
- Idade: 25-55 homens
- Interesses: fornecidos doc (copiar exatamente, ordem importa validação)
- Budget: R$30-35 iniciar, CBO
- Criativos: 3 fornecidos validados → NÃO rodar direto, criar variações (destacar-se leilão)
- Processamento: copiar criativos referência, jogar ChatGPT pedir variações, usar Ideogram gerar
- Observação: oferta validada mas primeira rodada sua = aprendizado Facebook, esperar 3-7 dias
- Não desistir: dinheiro investido CEO validação, produto vende (requer otimização estrutura)

## Low Ticket em Dólar - Método Esther

**Aula:** 178

- Produto: low ticket específico R$12 (em dólar 4x+ retorno)
- Comissão: 90% (pouco mais que SaaS porque produto recorrente, suporte, atualização)
- Afiliação: clique link drive → Hotmart → "solicitar afiliação" → 24h aprovação
- Informações produto: benefícios, modelo negócio, comparativos, lido em descrição Hotmart
- Funil vendas: Inlead (solicitar funil com e-mail conta Inlead) ou 24h entrega
- Cupom desconto: código "vonis" = 10% Inlead (passar para alunos)
- Config funil: clicar botão → redirecionar → colar link afiliado checkout
- Pixel config: configurações → pixel → ID + script HTML Facebook
- Campanha estrutura: orçamento R$20-30 CBO, público segmentado, idioma espanhol
- Localizações: mundo todo excluir (Brasil, Guiana Francesa, Guiana, Índia, Venezuela, África)
- Público: mulheres 25-55, interesses (desenvolvimento pessoal, teologia, etc)
- Copy/títulos: fornecidos doc → testar variações
- Criativos: validados fornecidos → modelar criar novas variações em Canva/IA
- Pré-requisito: conhecimento básico campanha Facebook (funil Inlead resolve muita coisa)
- Otimização: call semanal Seleta Comunidade analisa campanhas ao vivo

## Oferta Validada - Estruturador Latam

**Aula:** 181

- Produto: estruturador sermões em dólar (mesma ferramenta BR adaptada Latam)
- Afiliação: Hotmart → "solicitar afiliação" botão → 24h aprovação
- Obs importante: configurar perfil Kirvano 100% (nome, e-mail, telefone, doc, conta pagar) ANTES solicitar
- Atualizações: ferramenta testada validada traduzida vários países
- Funil Inlead: criar conta (cupom vonis = 10% desconto) → solicitar funil 24h → clicar compartilhar
- Edição funil: etapa 11 última → clicar botão compra → tipo navegação = redirecionar → colar link afiliado
- Pixel config: Inlead "configurações" → pixel/script → ID + script Facebook
- Importante também: configurar pixel Kirvano (ID + token) como outros produtos
- Publicar funil: botão compartilhar → copiar link → jogar campanhas Facebook
- Campanha básica: orçamento R$20-30 CBO, mundo todo excluir (Brasil, Gana francês, Guiana, Índia, Venezuela, África)
- Público: homens, idioma espanhol, interesses validados (copiar exatamente estrutura)
- Criativos: 7 fornecidos → base criação variações (ChatGPT pedir prompts, Ideogram gerar imagens)
- Alerta: criativos saturam, ofertas continuam vendendo → sempre criar variações
- Diferencial Ideogram: ferramenta IA 5 dólares gera 4 variações criativo simultaneamente
- Gratuito alternativa: ChatGPT imagem também funciona
- Estrutura campanha: compilado no drive ofertas validadas (tudo pronto copiar colar)
