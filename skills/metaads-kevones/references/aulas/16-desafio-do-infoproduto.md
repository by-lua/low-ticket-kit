# Desafio do Infoproduto!

## Aula 01 - Ofertas e Posicionamento

**Aula:** 141

Lançamento do desafio de 4 semanas (estruturado em episódios) para criar, estruturar, vender e escalar infoproduto do zero. 90+ alunos ao vivo com formato de call semanal.

### Filosofia: MVP Não Perfeição

- Criar mínimo produto viável (não precisa ser perfeito)
- Testar oferta rápido, melhorar com base em dados
- Vender produto bom que resolve dor (não porcaria)
- Exemplo: Seleta Comunidade lançou com muito menos conteúdo que hoje, melhorou com tempo/feedback

### Etapas do Desafio

1. Aula 1: Oferta + Marca
2. Aula 2: Copy + Página de Vendas
3. Aula 3: Criativos
4. Aula 4: Estrutura de Campanhas + Otimização + Escala

### Ideias Viáveis de Infoproduto

Facilitadores (resolvem dor específica, não curam tudo):

- **Agentes ChatGPT**: programa IA para tarefas (escrever cópias, resumir livros, etc.)
- **E-books**: manual de contratos, guias validados (Marcos Ramos faturou 5M+ com ebooks)
- **Planilhas**: para nichos (contabilidade, ajuste de ROI, organização, etc.)
- **Templates**: Notion, Canva com configurações pré-prontas (Central Financeira do Gestor = 8.000 reais com 372 vendas)
- **Checklists**: lançamento, YouTube, CEO, SEO, etc.
- **Combos**: ebook + template + checklist + ferramentas em um pacote
- **Modelos/Templates prontos**: Canva com 20+ variações para diferentes nichos

Evitar: emagrecimento, cura de doença, PLR, porcarias do mercado digital.

### Posicionamento: Marca Pessoal vs. Despersonalizado

**Marca Pessoal:**
- Você aparece, seu rosto, seu Instagram
- Gera mais relacionamento e confiança
- Maior conversão inicial
- Recomendado se já tem audiência

**Despersonalizado:**
- Página com logo, marca própria, padrão de cores
- Sem pessoa por trás (Dona Maria genérica)
- Exige estrutura visual mais profissional
- Vende para tráfego frio sem precisar de audiência

Recomendação: comece despersonalizado se sem audiência, depois evolua com marca pessoal.

### Estrutura de Marca

- Logo bonita
- Padrão de cores consistente em todos lugares
- Fontes padronizadas (2 tipos max)
- Elementos gráficos alinhados
- Se despersonalizado: criar Instagram/página após primeiras 5 vendas

### Pesquisa de Mercado

Validar nicho:
- YouTube: buscar tema, ver volume de visualizações
- Google Trends: pesquisas por palavras-chave
- TikTok: volume de conteúdo sobre assunto = indicador de mercado
- Exemplo: "Conselhos bíblicos para mulheres" = centenas de milhares visualizações no YouTube = mercado viável

Se existe dor (pessoas comentam, buscam, assistem) = existe mercado.

### Precificação

Estrutura do autor:
- Ticket baixo: R$47-R$97 (ebooks, templates, checklists)
- Ticket médio: próximas iterações
- Ticket alto: cursos, mentorias (exigem mais credibilidade/audiência)

Metodologia: quanto vou lucrar vs. quanto vou cobrar?
- Maleta do Gestor: R$97 com CPA R$16 = R$80 lucro inicial
- Black Friday: abaixou para R$47 com CPA R$10-15, continuou vendendo bem
- Princípio: se oferta boa, mesmo desconto continua atraente

### Orçamento Mínimo para Testar

- R$300-500/mês é o ideal para teste válido
- Possível com R$100 mas limitado
- Dica: usar cartão de crédito, pagar do lucro quando vender

### Estrutura do MVP

Aula 1 entrega:
- Definir oferta (facilitador viável)
- Definir posicionamento (pessoal ou despersonalizado)
- Pesquisar mercado (YouTube, Google, TikTok)
- Estruturar marca básica

Próximas aulas evoluem com copy, página, criativo, campanha.

## Aula 02 - Copy e Página de Vendas

**Aula:** 142

Segunda semana: estrutura de páginas de venda, tipos de funis, elementos de conversão. Demonstração prática de páginas rodando (Maleta do Gestor = 27.000 visitantes, 60% interação, 9.000+ conversões completas).

### Tipos de Estrutura de Venda

**1. X1 (WhatsApp direto)**
- Levar lead pro WhatsApp, vender lá
- Palestrante não recomenda (gosto pessoal): muito trabalho respondendo, automação necessária
- Usa para remarketing de quem iniciou compra
- Foto de perfil profissional essencial (não fotos genéricas de Google)

**2. Quiz (Recomendado como bom meio termo)**
- Funis dinâmicos que qualificam lead
- Plataforma: Inlead (cupom "Seleta comunidade")
- Custos: plano mensal vs. hospedagem/domínio de WordPress
- Vantagem: testa ao mesmo tempo personalidade do lead, qualifica antes da página de vendas

**3. Página de Vendas Estática**
- Hospedagem + Domínio (Rockit, Hosting): ~R$7-50/mês
- WordPress + Elementor (plugin drag-drop)
- Customização total
- Maior trabalho inicial

### Estrutura Ideal de Página de Vendas

**Proposta Única de Venda (Topo)**
- Resolva TODOS problemas do lead com o produto
- Exemplos: "Tudo que gestor precisa", "Venda o triplo em 30 dias", "Deixe tráfego conosco"
- Colocar NO TOPO, não depois

**Método/Usabilidade**
- Como aquilo funciona?
- O que encontra dentro?
- Como usar?

**Turbinar Oferta**
- Colocar benefício principal
- "Ainda tem mais..." → funis, modelos, templates, scripts
- Nunca apenas oferta principal isolada
- Estratégia: anúncio fala só da dashboard, página revela funis + modelos + checklist + suporte

**Quebra de Objeção**
- Feedback de clientes reais (áudio ou texto)
- Antes de preço, ao longo da página, após preço
- Confiança que product realmente funciona
- Sem feedback? pedir pra amigos testarem e darem opinião sincera

**Prova Social**
- Comentários, depoimentos
- Prints de resultados
- Casos de sucesso

**Âncoragem de Preço**
- Princípio do contraste: mostrar valor original vs. promoção
- "Pagaria R$59, mas hoje R$17,90"
- Demonstração de valor antes do preço

**Chamada para Ação**
- Para público quente (seguidores): botão no topo
- Para público frio (desconhecidos): botão embaixo APÓS ler tudo
- Usar "Saiba Mais" (qualifica) vs. "Compre Agora" (perde quem não convenceu)

**Garantia/Reembolso**
- Aumenta conversão
- Palestrante oferece 30 dias
- Baixa rejeição se produto bom

### Elementos Técnicos

**Cores**
- Padrão de cores coerente (criativo + página + checkout)
- Evitar contraste ruim (azul em verde = dor de cabeça)
- Impacta conversão diretamente

**Fontes**
- Máximo 2 tipos
- Mesmo padrão em criativo, página, entregável

**Funis Dinâmicos vs. Estáticos**
- Dinâmico (Inlead): quiz qualifica, depois página de vendas
- Estático: direto para página
- Dinâmico melhor para tráfego frio

### Exemplo de Página Rodando

Maleta do Gestor (Inlead):
- 27.000+ visitantes
- 60% taxa de interação no quiz
- 9.000+ chegaram até página de vendas
- Funil pergunta necessidades → recomenda solução personalizada

Estrutura:
1. Quiz: "qual é sua maior dificuldade?"
2. Respostas direcionam para propostas diferentes
3. Página de vendas customizada por resposta

## Aula 03 - Criativos

**Aula:** 143

Tipos de criativos que vendem: UGC (TikTok), conteúdo de valor, direto, carrossel. Estrutura mental: anúncio deve parecer conteúdo, não anúncio.

### Princípio Fundamental

Anúncio NÃO deve parecer anúncio. Se parece propaganda → descarte (skip). Pessoas amam comprar mas odeiam ser vendidas.

### Estrutura de Criativo que Vende

1. **Entreter** (sem ser engraçado)
2. **Desenvolver história** (problema → solução → resultado)
3. **Trailer, não filme**: mostrar o suficiente para curiosidade
4. Comparar com trailer de filme (Vingadores Ultimato) → audiência compra ingresso

### Tipo 1: UGC (Estilo TikTok)

- Pessoa pegando celular, contando história
- Legenda automática + música de fundo
- Simples de fazer, alto impacto
- Exemplo: "Sindicato dos SmartWatch vai derrubar vídeo" → explica promoção → "mande msg para garantir"
- **Exemplo do cliente (SmartWatch)**: 1.148 leads em 1 mês, custo R$1,79/lead (ao vivo ao gerenciador)
- Vende porque não parece anúncio profissional

### Tipo 2: Conteúdo de Valor

- Aula/dica dentro do anúncio
- Mostra como fazer X
- Final: "quer aprender mais? clica aqui"
- Não força venda, oferece conhecimento
- Exemplo: aula de traqueamento avançado com ferramenta de integração

### Tipo 3: Direto

- Imagem/vídeo + preço + CTA
- Funciona para público quente (já interessado)
- Ex: "iPhone novo, até 18 parcelas, chama no Zap"
- Funciona bem em casos específicos mas com público certo

### Tipo 4: Carrossel

- Múltiplas imagens/vídeos sequenciados
- Conta história por slides
- Cliente faturou 5M+ com carrouséis só
- Exemplo: "Será que vale a pena?" → proposta → feedback → preço final

### Recomendação Prática

Teste 3-5 criativos por conjunto:
- 2 vídeos (TikTok style + outro formato)
- 1-3 em imagem estática ou carrossel
- Repita criativo em diferentes públicos (matriz: público x criativo)

### Validação de Criativo

- Validado = fez venda
- Em teste = métricas secundárias (CTR >2%, taxa de engajamento, inicialização de compra)
- Não mexer em criativo que já vendeu
- Testar novos em paralelo, não isolado em campanha nova

## Aula 04 - Estrutura de Campanhas e Traqueamento

**Aula:** 144

Configuração prática de Pixel (Meta), teste de públicos, estrutura de campanha (CBO vs. ABO), duplicação eficiente.

### Traqueamento: Fundação de Tudo

**Pixel Meta (essencial)**
- Um pixel por produto
- ID do Pixel + Token (Advanced Matching)
- HTML do Pixel → cole na página de vendas (elemento HTML tag) ou Quiz (Inlead settings)

**Passos Traqueamento:**

1. Criar Pixel (Gerenciador Negócios → Conjunto de Dados → Adicionar Pixel)
2. Atribuir pessoas da equipe
3. Conectar à conta de anúncios
4. Instalar código HTML na página
5. Gerar token de acesso (Advanced Matching via API)
6. Colocar Token na plataforma de venda (Kiwify, Hotmart, etc.)
7. **Crítico**: Lista de Permissão (URL da página + URL do checkout)
   - Permite que Pixel rastreie eventos nessas URLs
   - Sem isso, perdem dados precisos

**Resultado Correto:**
- Page View (HTML instalado)
- Initiate Checkout (Token na plataforma)
- Conversion (API de conversão ativada)

Sem traqueamento correto = dados imprecisos = decisões erradas em campanha.

### Estrutura de Campanha (CBO - Campaign Budget Optimization)

**Nível de Campanha:**
- Orçamento (R$ total) é colocado A NÍVEL DE CAMPANHA
- Facebook distribui entre os Conjuntos (Ad Sets)

**Conjuntos de Teste (Públicos):**

1. **Aberto** (sempre funciona bem)
   - Sem segmentação, Facebook otimiza por criativo
   - Testar primeiro
   
2. **Segmentado por Gênero** (variação do aberto)
   - Ex: apenas mulheres
   
3. **Interesses** (3-5 interesses relacionados por conjunto)
   - Ex: Conjunto 1: Pastor, Espiritualidade, Teologia, Desenvolvimento Pessoal, Estudos Religiosos
   - Ex: Conjunto 2: Igreja, Autoconsciência, Confiança, Motivação

Teste mínimo: 3 conjuntos. Máximo: 5.

**Criativos por Conjunto:**
- 3-5 criativos REPETIDOS em cada conjunto
- Permite testar público x criativo simultaneamente
- Descubrir combos que funcionam (Público X + Criativo Y = vencedor)

### Teste vs. Escala

**Teste (CBO com múltiplos públicos):**
- Deixa rodando, Facebook aloca verba
- Se gastos só em um público = aquele está gerando melhor resultado
- NÃO mate a campanha quando começar a vender
- Apenas DESATIVE criativos que não venderam

**Erro comum:** criar campanha nova com o criativo que vendeu isolado
- Resultado: perde inteligência da campanha anterior, começa do zero

**Correto:** manter campanha, desativar maus criativos, manter bons, testar novos em PARALELO em mesma campanha.

### Duplicação Eficiente

Em vez de configurar tudo 5 vezes:

1. Configure 1 conjunto + 1 criativo (ad01)
2. Duplicar ad01 → ad02-05, mudar apenas a mídia (imagem/vídeo)
3. Duplicar o conjunto → segmentado-01, mudar apenas o público (interesses)
4. Duplicar segmentado-01 → segmentado-02, mudar apenas os interesses

Poupador de tempo enorme vs. configurar cada combinação do zero.

### Configuração Prática no Meta Ads Manager

1. **Nome da campanha**: Conversão + nome do produto + orçamento
   - Ex: "Conversão Esboços Listados R$25"

2. **Objetivo**: Vendas (compra)

3. **Nível de Campanha**: Orçamento (ex: R$25)

4. **Conjunto (Ad Set):**
   - Nome: Aberto / Segmentado-01 / Segmentado-02
   - Público: Aberto OU Interesses específicos
   - Objetivo: Maximizar Conversão
   - API de Conversão ativada (verde = configurado correto)

5. **Anúncio:**
   - Nível: Selecionar criativo (imagem/vídeo único ou carrossel)
   - Desativar: "Anúncio com Várias Variações", "Otimizações Automáticas" (bugam criativo)
   - Mídia: Original (não redimensionar)
   - Texto + Título + Descrição
   - CTA: "Saiba Mais" (qualifica) vs. "Comprar Agora"
   - URL: página de vendas
   - Pixel: ativado

6. **Programação**: Se tarde/noite → programar para amanhã (Facebook gasta rápido em pouco tempo)

### Validação de Resultado

- **Validado**: fez venda
- **Em teste**: CTR >2%, engajamento bom, inicialização de compra
- **Ruim**: tudo baixo

Sempre analisar métricas secundárias durante teste.

### Aviso Crítico

Não criar conta de anúncios isolada por produto (salvo exceção de nicho diferente). 
- Campanhas inteligentes dependem de dados agregados no nicho
- Misturar nichos diferentes na mesma conta = confunde o algoritmo

Estrutura ideal:
- 1 BM (Business Manager) = múltiplas contas de anúncios
- 1 Conta de Anúncios = 1 nicho
- 1 Pixel = 1 produto

## Resumo Geral - Desafio do Infoproduto

Estrutura completa do desafio (4 semanas):
1. **Oferta + Marca**: definir produto viável, posicionamento
2. **Copy + Página**: estrutura de conversão, funis
3. **Criativos**: tipos que vendem (UGC, valor, direto, carrossel)
4. **Campanhas**: traqueamento, públicos, estrutura CBO, duplicação eficiente

MVP filosofia: não perfeito, só viável. Teste → melhore com dados.
