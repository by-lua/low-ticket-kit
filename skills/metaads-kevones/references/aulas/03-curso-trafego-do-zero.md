## Preparativos Práticos

**Aula:** 79

- 3 pré-requisitos antes de criar qualquer estrutura: (1) usar um perfil de Facebook ANTIGO/movimentado (próprio ou de família/conhecido — perfil novo tem risco alto de bloqueio); não precisa estar ativo, só ter sido criado há tempo; (2) ativar autenticação de dois fatores no Facebook E no Instagram (dá credibilidade, evita bloqueio por "atividade suspeita"); (3) confirmar identidade no Facebook (enviar foto de documento frente/verso) — aumenta credibilidade e reduz chance de bloqueio futuro (spoiler do módulo de Contenção).
- Passo a passo 2FA: perfil → Configurações → Privacidade → Senha e segurança → Autenticação de dois fatores → seguir fluxo (código por SMS/e-mail ou app autenticador).
- Passo a passo confirmar identidade: Configurações → Dados pessoais → Confirmar identidade → preencher nome completo, CPF, foto de documento (melhor fazer pelo celular, usa a câmera). Quando perguntado o motivo, selecionar "vinculação de anúncios sobre temas sociais, eleições ou política" mesmo sem rodar esse tipo de anúncio — aumenta credibilidade.
- Repetir 2FA no Instagram (mesmo caminho: Configurações → Privacidade → Segurança → Autenticação de dois fatores).

## Como criar um gerenciador de negócios profissional

**Aula:** 80

- Gerenciador de Negócios (BM = Business Manager) é a "maleta de ferramentas" do gestor — onde ficam todos os ativos (páginas, contas de anúncio, Instagram, pixel etc.).
- Passo a passo criação: Facebook → pesquisar "Facebook Business" → entrar no 2º resultado (business.facebook.com) → Criar conta → nome da empresa (fictício serve) → seu nome → e-mail (o mesmo do login do Facebook pessoal) → Enviar → Concluir.
- Depois de criado: Configurações do negócio → Informações da empresa → Editar → preencher razão social (ou nome idealizado), país, endereço, CNPJ (ou CPF se não tiver CNPJ) → Salvar.
- Ativar 2FA na própria BM (Configurações → Autenticação de dois fatores → "todos") — só funciona DEPOIS de já ter 2FA ativo no perfil pessoal do Facebook/Instagram, senão o sistema expulsa o usuário da BM.
- Confirmar e-mail da BM (Configurações → e-mail → editar → colar e-mail → confirmar via Gmail).
- Adicionar forma de pagamento: Configurações do negócio → ⋯ (3 pontinhos) → Cobranças e pagamentos → selecionar a conta → Adicionar forma de pagamento → moeda SEMPRE BRL (real) se operar no Brasil, fuso SEMPRE São Paulo. Aviso: depois de escolher o MÉTODO de pagamento (cartão/PIX/boleto) para aquela conta de anúncios, não é possível trocar depois — decidir com cuidado.
- Recomendação forte: usar CARTÃO DE CRÉDITO (pré-pago em relação ao gasto: só paga o que usou; evita ficar com dinheiro preso em caso de bloqueio, diferente de PIX/boleto/transferência que já saiu da conta).
- Preencher dados do titular do cartão (nome, país, endereço, CPF/CNPJ) — se usar cartão de terceiro, usar os dados desse terceiro.
- Verificar domínio (se tiver site próprio): Configurações do negócio → Adequação e segurança da marca → Domínios → Adicionar domínio (sem "https://", só o domínio puro) → verificar via registro TXT no DNS (procurar no YouTube "como verificar domínio [nome da plataforma onde o domínio foi comprado] Facebook").

## Entendendo a hierarquia e seus ativos

**Aula:** 81

- Hierarquia: Facebook (manda em tudo) → dentro dele, a BM (central/maleta) → dentro da BM, os ATIVOS: conta de anúncios, página do Facebook, conta do Instagram, Pixel, domínio, catálogo, entre outros.
- O anúncio nunca aparece no perfil pessoal — ele aparece na PÁGINA conectada à BM (por isso a página é tratada como ativo).
- Lição desta aula é só conceitual: entender que a BM recém-criada ainda está vazia (sem página, sem conta de anúncios, sem Instagram conectados) — a próxima aula ensina a criar e conectar cada um desses ativos.

## Criando e conectando seus ativos

**Aula:** 82

- PASSO A PASSO — Conta de anúncios: BM → Contas de anúncio → Adicionar → Criar uma nova conta de anúncios → nome (ex.: "BM Seleta 01", numerar pensando em contas futuras) → fuso SEMPRE São Paulo → moeda SEMPRE BRL (não pode mudar depois) → Avançar → selecionar finalidade (empresa) → Criar → Atribuir pessoas (selecionar o próprio perfil, ligar todas as permissões) → Atribuir.
- PASSO A PASSO — Página do Facebook (forma "correta" segundo o Kevones: pelo próprio Facebook, não direto pela BM): Facebook → Ver mais → Páginas → Criar nova página → nome, categoria, biografia → preencher contato/telefone/e-mail/localização/horário (pode marcar "nenhum horário disponível") → Avançar → adicionar foto de perfil e capa (sugestão: Canva, grátis, templates prontos) → Avançar → número de WhatsApp (idealmente WhatsApp Business) ou pular → convidar amigos para curtir (aumenta credibilidade) → Concluir.
- Depois de criada: completar "nível de integridade" da página (publicação de boas-vindas, vincular WhatsApp, botão de ação — agendar/cadastrar/seguir/ligar/fale conosco/assistir vídeo etc.).
- Conectar a página à BM: copiar a URL da página → BM → Páginas → Adicionar → Adicionar uma página → colar URL → Adicionar página.
- PASSO A PASSO — Instagram: BM → Contas do Instagram → Adicionar → Conectar conta do Instagram → e-mail e telefone da conta → Salvar → Concluir. Depois, atribuir pessoas (mesmo processo da conta de anúncios) e conectar o Instagram à conta de anúncios (ativos conectados → atribuir → selecionar a conta).
- Conectar Instagram à PÁGINA (passo separado, feito pelo Facebook, não pela BM): Página → Gerenciar → Contas vinculadas → Ver → Conectar conta → login do Instagram → Continuar. WhatsApp se conecta só na página, nunca direto na BM.
- PASSO A PASSO — Pixel (aqui chamado "conjunto de dados" na interface atual): BM → Fonte de dados → Conjunto de dados → Adicionar → nome (um pixel por produto; se vários produtos, nomear por produto) → Criar → atribuir pessoas → conectar à conta de anúncios (ativos conectados → atribuir).
- Regra de decisão de pagamento: cartão de crédito > PIX/boleto/transferência, porque com cartão o dinheiro só sai depois do uso (protege caixa em caso de bloqueio); com PIX/boleto o saldo fica preso na conta se ela for restrita.

## Pixel! Como funciona e como instalar

**Aula:** 83

- Definição: Pixel é "o espião" — registra toda ação do lead após interagir com o anúncio (viu a página, viu conteúdo, clicou, iniciou checkout, comprou) tanto no site/e-commerce quanto nos ativos (seguiu, curtiu, comentou).
- 3 formas de instalação que SE COMPLEMENTAM (instalar todas, não escolher uma só):
  1. **Código HTML no site**: Gerenciador de eventos → Configurar Pixel da Meta → Instalar código manualmente → copiar código → mandar para quem criou o site (ou, se usou plataforma como Elementor/WordPress/Shopify, pesquisar no YouTube "como instalar Pixel [nome da plataforma]") → colar no <head> do site. Ativar "correspondência avançada". Verificar instalação com a extensão Chrome "Meta Pixel Helper" (compara o ID mostrado na extensão com o ID do gerenciador de eventos).
  2. **ID do Pixel na plataforma de checkout** (Hotmart, Kiwify, Monetizze etc.): copiar o número de identificação do Pixel (Gerenciador de eventos → Identificação) → colar no campo de Pixel da plataforma de checkout → procurar no YouTube "como instalar Pixel [nome da plataforma]" para o passo exato.
  3. **Token da API de Conversão**: Gerenciador de eventos → Configurações → rolar até "Gerar token de acesso" → copiar → colar na plataforma de checkout. Não duplica dados com o Pixel comum (cada evento tem ID único, Facebook deduplica automaticamente) — é só um reforço de captura.
  4. (Extra) Instalação via **parceiros do Meta** (Shopify, WooCommerce, WordPress etc.) — Configurações → Pixel do Meta → "procurar um parceiro", segue tutorial automático de integração.
- Teste de instalação: Gerenciador de eventos → Eventos de teste → colar link do site → navegar no site em outra aba → confirmar que aparecem Page View, View Content, Add to Cart, Initiate Checkout, Purchase conforme a navegação.
- Lista de permissão de domínio (passo que "pouca gente faz"): Configurações de eventos → Configurações → Permissões de tráfego → Editar → colar a URL do site (e também a URL do checkout, se for domínio diferente) — sem isso o Pixel não recebe os dados desses domínios.
- Rastreio manual de botão específico (ex.: botão de WhatsApp numa Landing page sem checkout próprio): Configurações → Configuração de eventos → Abrir ferramenta de configuração de eventos → colar link do site → Abrir site → selecionar o botão na tela → atribuir o evento desejado (ex.: Lead, Cadastro, Initiate Checkout). Também é possível marcar evento por URL (ex.: toda vez que a URL for a "página de obrigado", marcar como Cadastro).

## Como as Campanhas funcionam na Prática!

**Aula:** 305

## Como definir seu Objetivo de Campanha!

**Aula:** 306

- Objetivos de campanha do Meta Ads seguem o funil de vendas, agrupados em categorias:
  - **Reconhecimento**: Alcance (máximo de pessoas possível) e Reconhecimento de marca (quem tem mais chance de lembrar) — para quem ainda não te conhece.
  - **Consideração**: Tráfego (leva pra site/app/evento; metas: visitas no perfil Instagram, cliques no link, visualização de página) e Engajamento (curtidas, comentários, compartilhamentos, visualização de vídeo, mensagem no Messenger/Instagram/WhatsApp, instalação de app) — para quem já viu e está começando a considerar.
  - **Cadastro/Geração de leads**: coleta dados (formulário instantâneo, ligação) — para quem já engajou, antes de converter.
  - **Conversão/Vendas**: ação específica no site (compra, cadastro), vendas por catálogo, ou contato direto via Messenger/Instagram/WhatsApp para comprar — objetivo final do funil.
- Regra de uso: alcance/reconhecimento → quem não conhece; tráfego → quem já viu, pra conhecer mais; engajamento → quem já considera, pra interagir; cadastro → capturar dados de quem já engajou; conversão → gerar venda direta (site ou e-commerce/catálogo).

## Tudo sobre Conjuntos de Anúncios

**Aula:** 307

- No nível de conjunto, após escolher objetivo (ex.: Vendas) e tipo "manual" (não Advantage/inteligente): definir nome do conjunto (ex.: "aberto"), local da conversão (geralmente "site"), e meta de desempenho — REGRA: sempre usar "maximizar número de [conversões/cliques/conversas]" conforme o objetivo, nunca outra meta manual sem dados históricos.
- "Meta de custo por resultado" (definir um CPA máximo manualmente): só usar depois de já ter dados reais/histórico de CPA — sem dados, deixar automático.
- Orçamento e programação ficam no conjunto (ou na campanha, ver aula seguinte); programar início recomendado para meia-noite do dia seguinte (campanha roda 24h completas); NUNCA programar data de término fixa (risco de desligar campanha que está vendendo bem).
- Segmentação manual (clicar "mudar para opções originais" / "usar público original" pra sair do Advantage automático): localização (país/estado/cidade), idade, gênero, interesses/comportamentos (pesquisar palavra-chave, usar "sugestões" pra achar interesses relacionados), conexões (quem curtiu/segue a página), públicos personalizados (remarketing: quem visitou o site, seguiu Instagram, iniciou compra etc.), públicos semelhantes (Lookalike — parecidos com quem já comprou/engajou).
- Indicador de tamanho de público (barra verde/vermelha): quanto mais específico (ex.: só 1 cidade + 1 interesse muito nichado), menor o público e maior risco de ficar "muito específico" (barra vermelha) — Kevones diz que raramente usa segmentação demográfica/interesse muito fina, prefere manter aberto.
- Posicionamento: automático (deixa o Meta decidir) vs. manual (escolher feed/Stories/Reels/Facebook/Instagram especificamente) — útil quando só quer rodar num posicionamento específico.
- Dentro de uma mesma campanha, pode-se duplicar o conjunto e criar vários conjuntos com segmentações diferentes (ex.: "aberto" Brasil geral, "segmentado-01" só homens interessados em futebol, "segmentado-02" só mulheres 30+ em determinada cidade) — prática recomendada para testar públicos em paralelo.

## Orçamento! (CBO, ABO, Diário e Vitalício)

**Aula:** 308

- Tipos de orçamento: **Diário** (valor médio por dia; vantagem = flexibilidade de ajustar conforme performance; o Facebook pode gastar um pouco mais em dias bons, poucos reais de variação, mas raramente excede muito e só gasta mais quando está gerando vendas) vs. **Total/vitalício** (valor fixo pra duração toda da campanha; vantagem = controle total do gasto no período; desvantagem = menos flexível, exige ajuste manual). Recomendação padrão: orçamento DIÁRIO. Orçamento TOTAL só é necessário quando se precisa de horário de vinculação específico (ex.: delivery que só funciona 19h–23h) — só com orçamento total é liberada a opção "programação de anúncios" por horário/dia da semana.
- Estrutura: **CBO** (Campaign Budget Optimization, orçamento a nível de CAMPANHA) — você define um valor total e o Facebook distribui automaticamente entre os conjuntos conforme a performance de cada um (gasta mais onde converte melhor). **ABO** (orçamento a nível de CONJUNTO) — você define manualmente quanto cada conjunto específico vai gastar, independente da performance relativa.
- Preferência do Kevones: CBO — deixa o Facebook decidir onde gastar mais, permite testar mais conjuntos gastando menos verba total, ideal para quem tem orçamento menor. ABO só vale para um teste rápido e controlado onde se quer forçar gasto igual em cada público pra comparar performance de forma isolada.
- Regra de ajuste: aumentar orçamento gradativamente conforme performance (nunca pular de R$30 pra R$1.000 de uma vez — isso "quebra" a inteligência/aprendizado da campanha); reduzir ou pausar campanhas de baixo desempenho.
- Exemplo numérico dado: campanha de delivery com horário 19h–23h seg-sex, 18h–19h sábado, fechado domingo — mínimo recomendado de orçamento total ≈ R$30/dia × número de dias do período.

## Entendendo os Anúncios

**Aula:** 309

- Nível de anúncio = identidade (página Facebook + conta Instagram vinculadas) + formato + criativo (texto/título/descrição/CTA) + destino.
- Formatos: imagem/vídeo único (mensagem clara e direta), Carrossel (várias imagens/vídeos, pode reordenar), Coleção (mais imersivo, ideal com catálogo/e-commerce), Flexível (o Facebook escolhe o formato que acha que performa melhor — Kevones diz que não costuma usar, prefere imagem/vídeo único definido manualmente).
- Estrutura do criativo: **Texto principal** (a legenda, aparece acima no Facebook e abaixo no Instagram) → **Título** (aparece embaixo à esquerda no Facebook; é a 2ª coisa que o lead olha, depois do criativo, antes do texto — MUITO influente na conversão) → **Descrição** (opcional, complementa o título) → **CTA** (botão de chamada: "Saiba mais", "Comprar agora", "Fale Conosco", "Ver cardápio" etc. — escolher o que combina com o funil: ex. "Comprar agora" quando vai direto pra venda, "Fale Conosco" quando o funil termina em contato).
- Pode-se adicionar MÚLTIPLAS opções de texto principal e de título no mesmo anúncio — o Facebook testa as variações e prioriza a que mais performa.
- "Anúncios com vários anunciantes": útil só em e-commerce/catálogo (mostra o anúncio junto de produtos parecidos de outros anunciantes); desativar se o criativo é específico de um produto/serviço próprio.
- "Usar publicação existente": permite anunciar um post/Reels que já existe na página ou no Instagram, sem subir mídia nova — pode filtrar por tipo (Reels, Story, foto, vídeo, Carrossel).
- Destino: 90% das vezes é "site" (colar a URL); ativar eventos do Pixel na seção de rastreamento pra marcar conversão daquele anúncio específico.
- Dentro de um mesmo conjunto pode-se ter vários anúncios (duplicar e trocar mídia/texto/título) pra testar qual criativo performa melhor — a quantidade ideal de criativos por conjunto é ensinada em aula posterior (3 a 5, ver aula 311).

## Criando uma Campanha na Prática

**Aula:** 310

- Demonstração completa do zero: objetivo Vendas → Configuração manual → nome da campanha já indicando orçamento (prática de nomenclatura) → orçamento a nível de CAMPANHA (CBO) de R$70 → desativar opção de catálogo (produto não é e-commerce).
- Decisão aberto vs. segmentado: só usar conjunto "aberto" se o produto for de apelo amplo; produto nichado (ex.: "Maleta do Gestor", só interessa gestor de tráfego) exige conjunto SEGMENTADO desde o início.
- No conjunto: selecionar o Pixel do produto específico, otimizar para evento de COMPRA (não iniciar checkout, não adicionar carrinho — sempre o evento final desejado). Programação: se já passou de ~17h, programar pra meia-noite do dia seguinte (gastar o orçamento diário num período muito curto no fim do dia é ineficiente); se ainda é de manhã, pode deixar rodar no mesmo dia.
- Segmentação de exemplo: Brasil, homens 18–40, interesses "marketing digital" + sugestões relacionadas (publicidade online, marketing de redes sociais).
- Criativo: vídeo já validado anteriormente, 3 opções de título testadas ao mesmo tempo no mesmo anúncio (ex.: nome do produto / "Garanta agora" / promessa específica), 1 descrição, CTA "Comprar agora" (funil vai direto pra página via quiz).
- Hack de produtividade: montar o PRIMEIRO conjunto completo com criativo pronto, depois DUPLICAR esse conjunto e só trocar a segmentação nos demais (não precisa recriar o criativo a cada conjunto) — nesse exemplo, 3 conjuntos segmentados diferentes (variando idade/gênero/interesses) dentro da mesma campanha.
- Fluxo de status da campanha: Programada → Em análise → Ativa (se não violar política do Facebook). Em nível de anúncio: Em processamento → Processado → Programado/Em análise → Ativo.

## Otimizando Campanhas na Prática

**Aula:** 311

- Métricas principais e definições/fórmulas: **Impressões** (vezes que o anúncio foi exibido, total) · **Alcance** (pessoas ÚNICAS que viram) · **Cliques no link** (quantidade de cliques) · **CTR** = cliques ÷ impressões × 100 (mede relevância do anúncio pro público) · **CPC** = gasto total ÷ cliques (eficiência do gasto; quanto menor, melhor) · **Conversões** (ações valiosas: compra, cadastro etc. — "a métrica mais importante de qualquer campanha", não travar em métricas secundárias como CPM) · **CPA** = gasto total ÷ número de conversões (define se a campanha vive ou morre: se CPA > margem do produto, campanha no prejuízo) · **ROAS** = receita gerada ÷ gasto total (ex.: R$2.000 em vendas com R$500 de gasto = ROAS 4 = 400%).
- Ordem de leitura de desempenho: 1) impressões/alcance baixos → público muito pequeno/segmentado; 2) cliques/CTR baixos com alcance ok → criativo ou público errado; 3) CPC alto com CTR ok → criativo não comunica a essência do produto; 4) conversões baixas/CPA alto com CTR/CPC ok → problema no funil (público, criativo, copy, Landing page ou checkout).
- Otimizações de segmentação: refinar demografia (idade/gênero/localização) com base em quem realmente compra; ajustar interesses pra algo mais diretamente relacionado ao produto (ex.: interesse na marca específica em vez de categoria genérica).
- Teste A/B: trocar criativo/imagem/vídeo/texto sempre que não estiver convertendo — nunca insistir num criativo que não funciona só por "esforço investido". Testar também variações de CTA (não travar em "Saiba mais"). Regra numérica: MÍNIMO de 3 a 5 criativos por conjunto de anúncios.
- Orçamento/lance: só aumentar orçamento de campanhas que JÁ estão performando bem (ROAS positivo) — nunca "esperar performar" aumentando verba de algo mediano.
- Frequência: se a frequência (vezes que a mesma pessoa vê o anúncio) sobe E a performance cai ao mesmo tempo = sinal de saturação → pausar ou trocar o criativo.
- PASSO A PASSO — construir coluna de métricas personalizada (ordem recomendada, uma a uma via "Colunas → Personalizar colunas"): Vinculação (status) → Alcance → Frequência → Resultados → Valor usado → Cliques de saída → Custo por clique de saída → CTR de saída → Visualização da página de destino (+ custo por) → [se e-commerce: Adições ao carrinho + custo por] → Finalizações de compra iniciadas (total, custo por) → Compras (total) → Custo por compra (= CPA) → Valor de conversão em compra → ROAS.
- Métrica personalizada "grana no bolso" (lucro líquido direto no gerenciador): Criar métrica personalizada → Valor de conversão em compra MENOS Valor usado → nomear e salvar; adicionar à coluna.
- Rotina de otimização na prática: nível de ANÚNCIO primeiro (ordenar por CPA, desativar o que estourou o CPA, mesmo com ROAS positivo em outro anúncio do mesmo conjunto) → depois nível de CONJUNTO (comparar CPA/ROAS entre conjuntos) → depois nível de CAMPANHA. Se ainda não há venda nenhuma, usar métricas secundárias (visualização de página, CTR de saída, frequência, alcance) para diagnosticar o gargalo antes do CPA existir.
