### Identidade visual

Também poderei enviar materiais como:

- capa do produto;
- mockup;
- logotipo;
- paleta de cores;
- imagens do produto;
- screenshots;
- elementos gráficos;
- materiais da página de vendas.

Esses arquivos deverão ser utilizados como referência para identificar o **design system do produto**, incluindo:

- cores;
- tipografia;
- estilo visual;
- acabamento;
- elementos gráficos;
- tratamento das imagens;
- posicionamento da marca.

Quando o anúncio precisar mostrar o produto, utilize a capa, o mockup ou o material enviado com **máxima fidelidade visual**.

Não altere indevidamente:

- nome do produto;
- textos da capa;
- logotipo;
- autoria;
- cores principais;
- proporções;
- elementos técnicos importantes;
- identidade visual original.

Nesta primeira etapa, apenas analise e organize as informações. **Não gere os anúncios até que eu envie os criativos de referência.**
