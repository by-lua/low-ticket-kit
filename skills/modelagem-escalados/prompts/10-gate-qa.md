# PROMPT 10 — GATE DE QA (checklist antes de subir)

> Não é prompt: é o gate que **você** roda. Peça reprovada volta pro 06 ou 07 — nunca
> sobe "pra testar".

Abra a imagem. Não avalie pela descrição que o modelo deu dela.

## Bloqueadores — reprova direto

- [ ] Texto com erro de ortografia, letra deformada ou palavra inventada pelo gerador
- [ ] Headline ou CTA dentro da faixa de 250 px do topo / 350-400 px da base
- [ ] Prova fabricada: número, depoimento, avaliação, selo ou "mais de X alunos" que
      não veio do dossiê
- [ ] Nome de terceiro, logo de terceiro ou rosto de pessoa real da referência
- [ ] Capa/mockup com texto, cor ou proporção alterados
- [ ] Promessa fora do que o dossiê sustenta, ou termo da lista de restrição
- [ ] Dimensão errada (não é 1080×1080 exatos; 1080×1920 só na variação 9:16 pedida)
- [ ] Preço, prazo de garantia ou condição da oferta **diferentes** do bloco canônico
      do 02 — valor errado na arte é peça queimada, não é ajuste
- [ ] Selo de oferta inventado numa peça marcada `OMITIR` / `NÃO CABE` no 06

## Qualidade — reprova se dois ou mais falharem

- [ ] Hierarquia clara: dá pra dizer o que se lê primeiro
- [ ] Contraste suficiente para ler no celular no sol
- [ ] Legível em miniatura de 150 px
- [ ] Reconhecível como modelagem daquela referência (o mecanismo sobreviveu)
- [ ] Parece feita para este produto, não adaptada
- [ ] Consistente com o brandkit (cor, tipografia, acabamento)
- [ ] Não é genérica: a copy não serviria para o concorrente

## Diversidade da leva — avalie o conjunto, não a peça

- [ ] Nenhum formato repetido
- [ ] No máximo 2 peças por categoria
- [ ] Nenhum par de peças com a mesma persona **e** a mesma dor
- [ ] Os primeiros 3 elementos visuais diferem entre peças (a Meta lê similaridade)
- [ ] **Ao menos uma peça da leva carrega oferta, preço e garantia visíveis.** Leva
      inteira sem oferta não sobe
- [ ] **Toda peça aprovada está em 1:1 (1080×1080).** 9:16 só entra como extra quando pedido

Registre o resultado por peça: `APROVADA` / `REPROVADA — motivo` / `REFAZER COPY`.
